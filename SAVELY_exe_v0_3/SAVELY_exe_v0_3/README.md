# SAVELY.exe v0.3

Синий минималистичный дашборд для iPhone и компьютера.

- Профиль, аватар, общий XP, уровень и ранги.
- Редактирование навыка по нажатию на карточку; XP навыка можно менять, общий XP сохраняется отдельно.
- Квесты с XP и монетами.
- Магазин наград: фильм, игровой вечер, отдых; можно добавлять собственные награды и покупать их за монеты.
- Цели с зелёными прогресс-барами.
- История, экспорт и импорт JSON.
- Адаптивный интерфейс и базовый service worker.

Данные пока хранятся локально в браузере; синхронизация между устройствами ещё не подключена. Экспортируй резервную копию перед переходом между версиями.

GitHub Pages: загрузить содержимое архива в корень репозитория → Settings → Pages → Deploy from a branch → main → /(root).
